# BLACKED Free Website Package

## Included
- Mobile-first static website with Home, Innerwear, Boyfriend, and Wellness 18+ sections.
- Images shared in this conversation are copied into `assets/` with descriptive names.
- Search and category filters, product detail dialog, local wishlist, demo bag, local fit notes, date idea generator, message generator, conversation prompts, and 18+ self-attestation gate.
- No paid APIs, backend, npm, or external image hotlinks required.

## Free GitHub Pages publishing
1. Download and unzip this package.
2. Back up the current repository first.
3. Upload `index.html` and the entire `assets` folder to the repository root, preserving paths.
4. Commit the changes and enable GitHub Pages in Settings → Pages.
5. Open the published site on your phone and refresh.

## Limitations
This is a static front-end demo. There is no real payment, inventory, login/account, order placement, live booking, or admin analytics. Saved styles and fit notes use local browser storage. The Wellness age check is self-attestation, not formal identity verification. Images are references, not verified stock; product specifications, supplier, prices, safety certifications and image rights need verification before commercial launch. The source GitHub repository has not been changed automatically; this ZIP is for manual upload.
